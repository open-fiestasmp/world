# fiesta overworld

This is the raw `world` save from FiestaSMP (`fiestamc.neocities.org`), saved on 2026-11-21. Player data is in here too. The Nether and End are in the other repos.

## grab the files

Open [Releases](https://github.com/open-fiestasmp/world/releases), pick `snapshot-2026-11-21`, then download **Source code (zip)** and extract it. Use the folder with `level.dat`. The green **Code → Download ZIP** link gets the latest branch instead.

## use it

**Single-player:** copy the folder with `level.dat` into your Java Edition `saves` folder. Back up an existing save first. Dimension folder layouts change between Minecraft versions, so use the matching version's Nether/End folders if you want those too.

**Paper server:** stop it and back up its worlds first. Rename this extracted folder to `world`. Rename the companion repo folders to `world_nether` and `world_the_end`. Don't copy files into a running world; use a Minecraft/Paper version that can read this save.
